QUE ES ESTO
------------------------------------------------------------------------
Aplicacion web (Flask + SQLite) de gestion de empleados con:
  - Login y registro de usuarios
  - CRUD completo (crear, listar, editar, eliminar)
  - Busqueda y estadisticas
Incluye vulnerabilidades y malas practicas DE FORMA INTENCIONAL para
que las herramientas de analisis (Bandit, Flake8, PyLint) las detecten.

COMO EJECUTAR EL PROGRAMA
------------------------------------------------------------------------
1. Abrir una terminal (cmd o PowerShell) en esta carpeta
2. Instalar dependencias (solo la primera vez):
      pip install flask
   o bien:
      pip install -r requirements.txt
3. Ejecutar:
      python app.py
4. Abrir en el navegador:  http://127.0.0.1:5000/login

COMO REVISAR LA BASE DE DATOS (empleados.db)
------------------------------------------------------------------------
Opcion A - DB Browser for SQLite (gratis):
   1. Descargar en:  https://sqlitebrowser.org
   2. Clic en "Open Database" y seleccionar el archivo empleados.db
   3. Ver las tablas "usuarios" y "empleados" en la pestana
      "Browse Data"

Opcion B - Sin instalar nada (Python tiene sqlite3):
   Desde esta carpeta ejecutar:
      python -c "import sqlite3; \
c=sqlite3.connect('empleados.db'); \
print(c.execute('SELECT * FROM empleados').fetchall())"

Opcion C - Desde la propia interfaz web:
   Entrar al login y navegar por los empleados y estadisticas.
